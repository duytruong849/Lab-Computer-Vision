# LAB 3 – KẾ HOẠCH THỰC HIỆN

## 1. Mục tiêu

Tìm hiểu và thực hành phương pháp phát hiện biên Canny (Canny Edge Detector) trong xử lý ảnh số.

## 2. Nội dung thực hiện

- Tìm hiểu nguyên lý hoạt động và các bước của thuật toán Canny.
- Thực hiện phát hiện biên bằng OpenCV và Scikit-image.
- So sánh kết quả Canny với Sobel và Laplacian.
- Khảo sát ảnh hưởng của Gaussian Sigma và các ngưỡng thấp, cao.
- Thử nghiệm trên các loại ảnh khác nhau: ảnh nhiễu, ảnh tương phản thấp và ảnh nhiều chi tiết.
- Kết hợp Canny với các kỹ thuật hình thái học và tìm đường viền (Contours).
- Tìm hiểu khả năng áp dụng Canny trên ảnh màu và video.

## 3. Công cụ và thư viện

- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-image
- Jupyter Notebook
- HTML, CSS và JavaScript cho phần demo trình duyệt.

## 4. Sản phẩm đầu ra

- Notebook thực hành `Lad_3.ipynb`.
- Trang demo phát hiện biên Canny `Lab3.html`.
- Kết quả trực quan được lưu trong notebook.
